08 / CHATGPT SETUP

ChatGPT 接入教程

需要在 OpenAI Platform 和 ChatGPT 网页中由用户完成授权。

  1. 在 OpenAI Platform → Tunnels 创建或选择 ChatCode 专用 Tunnel，并将目标 ChatGPT workspace 与 Platform organization 关联。管理 Tunnel 需要 Tunnels Read + Manage。
  2. 从 Runtime API keys 创建单独的运行密钥，授予 Tunnels Read + Use；把密钥粘贴到上方密码框保存。不要使用 OpenAI Admin Key 作为运行密钥。
  3. 下载官方 Windows 客户端，填写 tunnel-client.exe 路径和 Tunnel ID，保存配置，运行凭据与 metadata 检测，再启动连接。保持 ChatCode 与 tunnel-client 运行。
  4. 在 ChatGPT 设置 → Connectors / Plugins 添加自定义 MCP server，Connection 选择 Tunnel，选择同一 Tunnel，完成风险确认并创建应用“ChatCode”。根据当前界面，可使用“Add custom MCP server”，旧版入口可能显示“Apps → Create”。
  5. 在新对话中选择或 @提及 ChatCode，调用 list_workspaces 或只读文件工具；只有 ChatGPT 网页中真实发现工具并成功调用后，才算网页端接入完成。

ChatGPT Business、Enterprise/Edu 的自定义 MCP 连接受 workspace 管理员策略控制。Pro 目前只支持受限的只读/搜索能力。若创建入口或写工具被禁用，请联系 workspace 管理员；ChatCode 不会绕过权限，也不会把 Tunnel 健康状态冒充为 ChatGPT 接入成功。
